# FormNET MCP tools

Written by `formnet agents sync` from the server's own tool list; `formnet agents check` fails when it is stale. Do not edit by hand.

Protocol 2026-07-28 on stdio (`formnet mcp`), and the initialize handshake of 2025-11-25, 2025-06-18, 2025-03-26 for older clients. 10 tools: 6 read-only, 1 writing only under `[data]/exports`, 3 needing the person's approval.

| Tool | Class | What it does |
| --- | --- | --- |
| `list_flows` | read-only | Read-only. Lists the exchanges FormNET's proxy recorded, newest last, without headers or bodies: method, URL, status, kind, sizes, timing and the process that sent it. Use it to see what a program sent, to find a flow id for get_flow, or to poll for new traffic by passing the last_seq of the previous answer as since. Filters are those of the FormNET API (host, domain, kind, client, q, since, pending); limit defaults to 25 and returns the newest matches. Kind refused lists programs that rejected FormNET's certificate. |
| `get_flow` | read-only | Read-only. Returns one recorded exchange by id: request and response headers, timing, TLS details and the captured bodies. Use it after list_flows to read what a request actually carried or what came back. Bodies are cut to max_body_bytes (default 8192, at most 65536) and flagged truncated when cut, as text when UTF-8 and base64 otherwise. Authorization, Proxy-Authorization, Cookie and Set-Cookie values always read [redacted]. |
| `list_hosts` | read-only | Read-only. Lists every host the proxy has seen with totals, most traffic first: flows, errors, bytes each way, first and last seen, whether anything was opened, the processes that reached it and FormNET's reading-aid label. Use it for an overview of where traffic goes before narrowing with list_flows. The label (category, owner) is a hint about the host, not a verdict. |
| `machine_snapshot` | read-only | Read-only. Returns the latest table of every connection this computer holds and the process that owns it, from the running FormNET (the same table as `formnet snapshot`). Use it to see which programs talk to the network even when they ignore the proxy. Filter by process name, pid or state (ESTABLISHED, LISTEN, ...); limit bounds both lists (default 50) and truncated says when more matched. |
| `proxy_status` | read-only | Read-only. Returns the proxy's address, whether it is listening, the interception mode (auto, on or off) and whether HTTPS is opened now, the passthrough list, the root certificate path, and the environment variables that point a program at the proxy. Use it first in any task that routes a program through FormNET, and to read back a change made with set_interception or set_passthrough. |
| `ca_info` | read-only | Read-only. Returns FormNET's root certificate: path, common name, SHA-256 fingerprint, expiry, whether this computer trusts it, and the exact commands that trust and untrust it on this system. Use it when HTTPS is only counted, when a program refuses the certificate, or when the person asks how to trust or remove the root. Show the command for the person to run; never run it, never invent another, never ask for the private key. |
| `export_har` | writes under exports | Writes a file. Saves the matching flows as a HAR 1.2 file under FormNET's data folder, in [data]/exports only, and returns its path; it never writes anywhere else and never replaces an existing file. Use it when the person wants a recording to open in a browser's developer tools or another HAR viewer. file_name is a plain name (letters, digits, dot, dash, underscore; .har is added), never a path. Credential headers are redacted by default. include_secrets=true writes them as captured: that is an approval choice, so ask the person before setting it. Tunnels and refused flows have no HTTP shape and are left out. |
| `clear_flows` | needs approval | Needs approval: destructive. Forgets every flow FormNET holds, for every program, in the web client too; it cannot be undone. Use it only when the person asks to start a clean recording. Export first with export_har if anything may be needed later. |
| `set_interception` | needs approval | Needs approval: changes the proxy for every program using it, and is kept for FormNET's next start. Sets whether HTTPS is opened: auto opens it while this computer trusts the root, on opens it always, off tunnels it and only counts hosts and bytes. Use it when the person wants HTTPS contents recorded or wants interception stopped. With on and an untrusted root, programs that check certificates refuse the proxy. Returns the proxy status read back. |
| `set_passthrough` | needs approval | Needs approval: changes the proxy for every program using it, and is kept for FormNET's next start. Replaces the whole list of hosts whose HTTPS is tunnelled without interception. Use it for programs that pin certificates (their flows show kind refused): add their hosts so they work through the proxy again, counted but not opened. Read the current list with proxy_status first and send it back with the change. Returns the proxy status read back. |

Full input and output schemas are in `agents/tools.json` at the repository root.
